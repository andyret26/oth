# Domain Documents

## Layout
This project uses a **single-context** layout.

- **Glossary**: The primary glossary of terms and domain concepts is located in `GLOSSARY.md` at the root of the repository.
- **Architecture Decision Records (ADRs)**: Architecture decisions are documented in `docs/adr/`.

## Consumer Rules
- When looking up domain terms, always refer to `GLOSSARY.md` first.
- When evaluating architectural changes, review the records in `docs/adr/`.
- Updates to domain definitions should be reflected in `GLOSSARY.md`.
